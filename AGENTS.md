# Orientações para agentes e colaboradores

Este projeto usa uma skill portável de documentação: [Documentação Profissional](.github/skills/documentacao-profissional/SKILL.md).

Antes de criar ou modificar README, requisitos, casos de uso, manual, arquitetura, contratos, relatório, imagens ou release:

1. Leia a skill completa e o [perfil documental do projeto](docs/PROJECT_DOCS_CONFIG.md).
2. Preserve a distinção entre PROPOSTO, DECIDIDO, IMPLEMENTADO, TESTADO e VALIDADO EM CAMPO.
3. Mantenha README como apresentação profissional e navegação, não depósito técnico.
4. Atualize docs técnicos, manuais, decisões e backlog conforme a mudança.
5. Não invente screenshots, ensaios de hardware, comandos de instalação ou métricas.
6. Respeite a [identidade visual aprovada](docs/IDENTIDADE_VISUAL.md).
7. Em dúvida sobre segurança elétrica, não publique uma topologia como esquema de instalação validado.

A skill é reutilizável em outros projetos copiando `.github/skills/documentacao-profissional/`, sem carregar este `AGENTS.md` ou o perfil local.
